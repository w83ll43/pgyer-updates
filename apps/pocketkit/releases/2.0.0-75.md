# 2.0.0（75）

- 新增完整凭据保险库，管理密码、笔记、卡片、身份与开发密钥，支持文件夹、收藏和搜索。
- 新增 TOTP 验证码与 ES256 通行密钥，接入系统填充；真实设备仍需有效签名授权。
- 新增 iOS 26 Apple 密码系统交换及 CSV 导入导出，导入前预览，明文导出需确认。
- 优化备份为独立模块，统一归档、加密、WebDAV 版本与恢复点；凭据备份始终加密。
- 优化保险库分组列表和备份预览，提取通用 UI 组件；采用新数据与备份格式，不保留旧版兼容。

兼容签名测试版：仅支持证书登记设备；真实设备的系统填充、通行密钥、Apple 密码交换和 iCloud 分发仍待验收。
旧格式不迁移；本机恢复点不上传，跨设备请使用加密文件或 WebDAV。
