# 3.1.0（78）

- 新增手机播放器，支持本地、网络直链与 HLS 点播、字幕及真实片源清晰度切换。
- 新增漫画／小说共用阅读器，支持图片、CBZ／ZIP、UTF-8 TXT 和简化 EPUB，以及书签和进度恢复。
- 新增本地弹幕、手势调光调音、全屏切换与紧凑面板，默认采用拾器配色。
- 新增可组合控件、JSON 布局与自定义配色，提供 URL Scheme 及独立 Swift Package。
- 新增 Kazumi XPath 规则导入、搜索、线路选集与解析播放，重试保留进度和字幕。

规则暂不支持 API 模式、验证码及 Cookie／Referer 桥接；直播、DRM 和在线弹幕服务未开放。兼容签名仅支持证书登记设备；真实手机及完整长片仍待验收。
