# 3.8.0（85）

- 新增 HLS 点播磁盘缓存，支持 4 小时以内、无 DRM 的片源，切换缓存时保留进度。
- 优化播放器面板，播放设置、选集和插件等功能统一使用同一尺寸和配色，切页后可逐层返回并保留视频画面。
- 新增选集内的磁力资源入口，以及一起看的连接、聊天、在线与请求分栏。更新房间服务后支持单人审批。
- 新增点播播放器内的系统解码与 mpv 切换，支持 Metal、显示刷新同步和 Anime4K，可从 Files 导入 ASS 字幕，已导入的字体在换片或重开后仍可使用。
- 新增批量离线下载，强退后重开可恢复队列。支持续传的直链文件从已下载位置继续，HLS 点播复用匹配的完整分片，包括带内容调度、URI 变量和 fMP4 字节范围的片源。
